# Raiyan A. Malik — Th3BlackHol3 Portfolio

A premium, responsive, single-page portfolio built with plain HTML, CSS and JavaScript. It is designed to deploy directly to GitHub Pages with no build step and no backend.

## Files
- `index.html` — page structure and content
- `style.css` — theme, responsive layout, 3D visual styling
- `script.js` — dynamic content, animations, counters, particles, mobile navigation and interactions

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will publish the site.

## Custom domain
Add a `CNAME` file containing your domain if you later connect a custom domain.

## Optional personalization
The layout intentionally uses a polished placeholder cyber visual in place of a personal portrait. To make the hero more personal, add a professional headshot later and swap the right-side visual for your photo while keeping the same visual language.
