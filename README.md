# Th3BlackHol3 — Cinematic 3D Portfolio

A dark, cinematic cybersecurity portfolio for Raiyan A. Malik / Th3BlackHol3.

## Visual system
- **Black** — primary foundation, deep-space backgrounds, glass surfaces
- **Electric Blue** — active systems, links, highlights, security telemetry
- **Red Wine** — threat/risk accents, secondary highlights, timeline contrast

## Highlights
- Three.js 3D singularity / security core
- Multi-layer orbital rings and rotating wire geometry
- Floating holographic HUD panels
- 3D security nodes and transparent wire cubes
- Electric-blue + red-wine lighting
- Perspective grid floor and particle field
- Pointer-reactive hero movement
- 3D tilt cards and project rows
- Scroll reveal animations
- Responsive layout and graceful WebGL fallback
- Accessible project case-study modals

## Run locally
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`.
